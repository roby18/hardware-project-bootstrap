# Bring-up 验证清单 — {{PROJECT_NAME}} @ {{BOARD_VENDOR_MODEL}}

> 规则：逐级点亮，每级是一个 20–50 行的最小固件；上一级不过不进下一级。
> 烧录必须由人工确认目标设备；每级通过后在 PROGRESS.md 记录日志/现象。

## L0 上电安全检查（不接芯片/首次插电前）

- [ ] 核对供电电压：万用表量 3.3V（{{允许范围}}）、1.8V（如有）
- [ ] 电源不短路：量 3.3V 对 GND 电阻无异常低阻
- [ ] USB 线与口确认：{{原生 USB / 桥接}}，设备管理器出现预期端口
- [ ] 外设使能脚上电默认态安全（功放静音、电机停转、负载关断）
- [ ] 预期现象：板子不发烫、无异味、电流 {{< X mA}}

## L1 下载链路与串口日志

- [ ] 能读到芯片信息：`esptool.py --chip {{CHIP}} -p {{COMx}} flash_id`
- [ ] flash_id 输出与 board.md 记录一致（容量/厂家）；不一致先改档案
- [ ] 烧录最小 Hello World，monitor 看到启动日志与打印
- [ ] 手动 BOOT/RESET 时序验证（短按 BOOT + RESET 进下载，如板子设计如此）
- [ ] 预期现象：稳定复位重启，无反复 brownout / 看门狗刷屏

## L2 引脚事实：点灯

- [ ] 普通 LED（如适用）：1Hz 闪烁，确认有效电平与颜色
- [ ] WS2812（如适用）：红绿蓝白各亮一次，确认灯序与数量
- [ ] 使用的引脚严格来自 board_pins.h；通过后该引脚事实标记为「实测确认」
- [ ] 预期现象：无 LED 的相邻脚误亮、无异响、电流在预算内

## L3 用户输入

- [ ] 每个按键/编码器：串口打印原始电平事件，逐键人工按一遍
- [ ] 核对接通方向（按下读 0 还是 1）、抖动表现
- [ ] strapping 脚上的按键：长按/上电按住都不会意外进下载模式（BOOT 除外）
- [ ] 预期现象：每个物理输入恰好产生预期事件，无串键

## L4 总线扫描

- [ ] I2C scan：打印总线上全部地址，与板载器件逐一对应
- [ ] 扫不到先查：上拉、供电、电压域、SCL/SDA 是否接反；不写业务驱动
- [ ] SPI：环路自测（MOSI→MISO 短接）或读已知 ID 寄存器
- [ ] UART：对端回环或抓波形确认波特率
- [ ] 预期现象：地址/ID 与 datasheet 完全一致

## L5 逐外设点亮（按需勾选）

- [ ] ADC：已知电压输入读数换算误差 {{< 5%}}；电池分压校准两点
- [ ] 显示：背光 → 复位时序 → 整屏纯色 → 驱动 IC ID
- [ ] 音频：功放禁默前无声爆；正弦波输出；录音回环
- [ ] 存储：读写速率与掉电保持
- [ ] 无线：RSSI、连接稳定性、峰值电流下不 brownout
- [ ] 其他：{{外设各自的可观察标准}}
- [ ] 每个外设点亮后回填 board.md 的「实测地址/现象」列

## L6 集成与契约验证

- [ ] 纯逻辑宿主测试全绿（协议、状态机、消抖等）
- [ ] 业务固件编译零警告（-Wall -Werror）
- [ ] 通信契约：报文 golden vector（真实抓包字节）逐字节通过
- [ ] USB/BLE 对端（App）按兼容版本完成握手
- [ ] 长时间烤机：{{时长}}，观察内存泄漏、漂移、温升、功耗

## L7 低功耗与异常（如产品需要）

- [ ] 睡眠电流实测 {{< 目标 μA}}；唤醒源逐一验证
- [ ] 欠压/掉电瞬间不写坏 Flash/NVS
- [ ] 异常断连恢复、看门狗、panic 日志落盘
